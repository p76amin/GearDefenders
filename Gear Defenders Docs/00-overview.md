## Elevator pitch

Gear Defenders is a free-to-play mobile placement / idle-collection hybrid: you build a living war machine by placing **troop gears** and **support gears** around a **Power Core**. Connected gears continuously charge and spawn combat units that push across a lane-based battlefield toward the enemy castle while defending your own wall/castle HP. Between battles, gacha summons, troop/king upgrades, castle capacity, and seasonal modes deepen a classic midcore progression loop.

## Genre positioning

| Axis | Placement |

| Core verbs | Place → connect → merge → spawn → push / hold |
| Session feel | Short tactical runs with real-time unit combat |
| Meta feel | Idle-collection / gacha RPG progression (troops, kings, jewels, passes) |
| Closest family | Tower-defense *adjacent* (defend castle) + auto-battler *adjacent* (spawned units fight) + merge-placement puzzles |

Official marketing framing: *“idle collection” + “strategic adventure”* (store copy). Community framing: often compared to tower-defense / idle battle, but skill expression is more about **board topology, merge economy, and warband focus** than classic tower placement.

---

## Design pillars (inferred from systems)

1. **War machine as puzzle** — The board is a gear network; connectivity and merge discipline beat raw spam.  
2. **Focused power, not roster breadth** — Community and guides strongly reward concentrating upgrades on a small warband (often 2–4 troops).  
3. **Dual fantasy: defend & invade** — Same spawn engine both holds your wall and races to destroy the enemy castle.  
4. **Support gears as run modifiers** — Mirror / production / economy / repair gears create distinct run strategies.  
5. **Vertical progression via Kings & gacha** — Kings, stars, jewels, and equipment convert meta grind into battle power.

## High-level content snapshot (confirmed public)

- **100+ campaign levels**; enemy fantasy factions cited in store copy: goblins, mummies, yetis; later chapters (e.g. Underwater World, Pirate Ship) via patch notes.  
- **Difficulty tracks** discussed by community: Normal / Elite / Nightmare (player progress reports).  
- **Endless Mode** with wave scaling and seasonal Battle Pass / King Fragments.  
- **Ranked Trials / Ranked Match**, King Equipment + Jewels, Wall upgrades/decorations, Patrol idle rewards, periodic festivals (Forge Festival, Artisan Fest, Summer Bash, etc.).  
- **10+ troop types** at launch messaging; roster expanded with Legendaries/Mythics (Thunder Caller, Elephant Knight, Catapult, etc.).
