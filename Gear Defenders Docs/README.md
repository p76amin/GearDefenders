## Confidence legend (used across docs)

- **High** — Multiple consistent public sources or official store/patch text.  
- **Medium** — Strong community consensus or single detailed guide.  
- **Low** — Sparse mentions; treat as leads for playtesting.  
- **Unknown** — Not found; do not invent stats.

---

## Key community consensus (snapshot)

- **Paladin** is the premier troop; **Paladin + Ninja** (or Arbalist) is the most repeated optimal pairing.  
- **Mirror, Coin Bag, production gears (Accelerator/1.5x), Repair, Level-up/Morale** define strong support loadouts.  
- **Focus upgrades** on a small warband; Endless cares about **average troop level**.  
- Ads are the main experiential complaint despite gameplay praise.
